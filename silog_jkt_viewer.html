Perubahan Desain dari Spesifikasi Sebelumnya

          
    
            
  1. Semua atribut dilengkapi tipe data SQL dan ukurannya (VARCHAR, INT UNSIGNED, DATE, DATETIME, ENUM).
    2. 
            
  2. Kelas PetugasBPBD dan PetugasPosko digabung ke tabel pengguna dengan kolom peran dan CHECK constraint.
    3. 
            
  3. Ditambahkan relasi langsung Posko - Bencana (kolom id_bencana pada tabel posko) untuk mendukung fitur lokasi dan rekomendasi prioritas.
    4. 
            
  4. Kolom selisih penerimaan tidak disimpan di kolom fisik, melainkan dihitung on-the-fly (jumlah - jumlah_diterima).
